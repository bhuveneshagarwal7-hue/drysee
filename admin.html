Google Sheets Cloud Sync (Free)

Want orders to automatically record into a Google Sheet in real-time? Paste your Google Apps Script Webhook URL below:

Quick Setup (3 minutes):
1. Open a new Google Sheet.
2. Click Extensions → Apps Script.
3. Paste this free webhook code: 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.orderId, data.customer.name, data.customer.phone, data.total, data.method, data.status]);
  return ContentService.createTextOutput("OK");
}
4. Click Deploy → New Deployment → Select Web App (Who has access: Anyone).
5. Copy the generated Web App URL and paste it above!
